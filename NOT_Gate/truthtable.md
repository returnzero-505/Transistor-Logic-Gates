# NOT Gate

## Objective
To design and simulate a NOT gate using a transistor.

## Truth Table

Input (A)  |  Output (Y) 

    1      |     0
    0      |     1
    
## Working Principle
A NOT gate produces the opposite of its input.

When the input is LOW (0), the output is HIGH (1).
When the input is HIGH (1), the output is LOW (0).

## Simulation
The circuit was designed and simulated using Tinkercad.

## Observation
The simulated output followed the expected NOT gate truth table.
