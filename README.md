# Transistor-Based Logic Gates

## About the Project

This project explores the implementation of fundamental digital logic gates using discrete transistors and basic electronic components.

The objective was to understand how transistors function as electronic switches and how their switching behaviour can be used to perform basic logical operations.

All five circuits were designed and simulated using Tinkercad.

## Logic Gates Implemented

1. NOT Gate
2. NAND Gate
3. NOR Gate
4. AND Gate
5. OR Gate


## Components Used

- NPN transistors
- Resistors
- LEDs
- DC power source (6V)
- Connecting wires

*The exact components vary depending on the circuit.*

## Simulation and Verification

Each circuit was tested with different input combinations. The resulting outputs were observed and compared against the corresponding logic gate truth tables.

## Project Structure

Each gate has a separate directory containing its circuit screenshot and observations.

## Learning Outcomes

Through this project, I explored:

- Transistor switching behaviour
- HIGH and LOW logic states
- Basic digital logic operations
- Construction of logic gates using discrete components
- Circuit simulation and output verification
